# TRANSIT CONTRACT

Implementá el Transit estándar Ultimate según las decisiones congeladas.

Debe existir una única autoridad para nuevas decisiones.

Reglas:

```text
effective_distance_per_day = 500 km

outbound_days =
ceil(distance_km / 500)

OWN cycle_days =
ceil((distance_km * 2) / 500)

EXTERNAL cycle_days =
null

arrival =
dispatch + outbound_days - 1

OWN available_again =
dispatch + cycle_days
```

Los helpers legacy no deben modificarse.

Agregar tests de frontera como mínimo:

```text
120 km  → 1 outbound day
500 km  → 1
501 km  → 2
1000 km → 2

OWN 480 km
→ outbound 1
→ cycle 2
```

No duplicar esta fórmula en módulos posteriores.

# CANONICALIZATION / FINGERPRINTS

```text

↓

↓

Artifacts
↓
content SHA256

Package + Manifest
↓
result_fingerprint
```

Evitar cualquier ciclo de hash.

Excluir de fingerprints matemáticos:

- signed URLs;
- current permissions;
- current approval overlay;
- display-only metadata;
- timestamps que no pertenezcan a la decisión matemática.

Mismo contenido canónico debe producir mismo hash.
