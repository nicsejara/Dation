# 3. ACTIVE CAPACITY DIMENSIONS

El engine debe respetar simultáneamente todas las dimensiones activas del Model.

Ejemplos:

```text
PALLETS
WEIGHT
VOLUME
UNITS
```

Si Model usa:

```text
PALLETS + WEIGHT
```

un Trip debe satisfacer ambas.

No reducir factibilidad a la dimensión primaria de reporting.

La dimensión primaria sirve para reporting, NO para ignorar restricciones físicas adicionales.

---

# 4. GUARANTEED CAPACITY

Factibilidad utiliza:

```text
guaranteed_capacity
```

NO:

```text
maximum_capacity
```

salvo que exista confirmación contractual futura explícita.

Ejemplo:

```text
guaranteed pallets = 26
maximum pallets = 30
```

Una orden non-split de 28 pallets:

NO cabe.

No usar maximum para mejorar artificialmente cobertura.

---

# 5. SPLIT / NON-SPLIT

## Non-split

Una demanda:

```text
split_allowed = false
```

debe:

- viajar íntegramente en un solo Trip;
- o quedar residual/unassigned.

Nunca:

```text
26 + 2
```

si la orden requiere 28 y ningún recurso puede transportar 28.

## Split

Cuando está permitido:

la fracción debe conservar proporcionalmente todas las dimensiones activas.

No dividir pallets independientemente del peso/volumen correspondiente.

# 6. CONSERVATION


No perder demanda.

No crear demanda.

No ocultar residual.

# 7. EXTERNAL RESOURCES

Los recursos EXTERNAL representan oferta finita durante el horizonte.

`services_available` limita la cantidad total de servicios/trips utilizables según contrato.

Ejemplo:

```text
Resource E1
services_available = 2
```

NO puede generar:

```text
3, 4, 5...
```

Trips abstractos.

El límite no se resetea por día o lane salvo contrato explícito.

`availability_source = ASSUMED` debe conservarse como assumption/evidence.

No convertirlo a CONFIRMED.

---

# 8. OWN RESOURCES

OWN representa capacidad interna reutilizable.

Debe respetar:

```text
units_available
```

y factibilidad temporal.

Una única unidad física lógica NO puede atender simultáneamente múltiples ciclos incompatibles.

No multiplicar capacidad de un Trip por `units_available`.

Ejemplo:

```text
1 truck
capacity = 26 pallets
units_available = 3
```

NO significa que un único Trip tenga capacidad 78.

Significa que existen hasta tres unidades equivalentes disponibles para ciclos compatibles.
