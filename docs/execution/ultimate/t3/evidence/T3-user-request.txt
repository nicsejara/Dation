# 1. LOGISTICS MODEL

Implementá el concepto durable y reusable definido en el Master Plan.

> una configuración reusable de una operación logística.

NO una semana ni una ejecución.

```text
Operating Role
Transport Pattern
Resource Sources
Capacity Dimensions
Primary Reporting Dimension
Split behavior
Cost model configuration
Compatibility assumptions
Network assumptions

```

# 3. MODEL VERSIONING

Logistics Model debe tener versiones publicadas append-only.

Debe poder existir:

```text
Model
 ├── Version 1
 ├── Version 2
 └── Version 3
```

Una Model Version publicada:

- es inmutable;
- puede ser reutilizada por múltiples Cases;
- no cambia Cases históricos;
- conserva contract/config hashes;
- no se sobreescribe.

Editar un Model publicado debe generar una nueva versión cuando corresponda.
