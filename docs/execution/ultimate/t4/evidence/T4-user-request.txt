# 3. TRANSPORT DEMAND CONTRACT

# 4. TRANSPORT RESOURCE CONTRACT

Debe soportar:

```text
OWN
EXTERNAL
```

con campos condicionales.

## Common

- resource_id;
- source;
- capacities activas;
- guaranteed capacity;
- compatibility;
- lane/network constraints;
- cost model correspondiente.

## OWN

- units_available;
- base;
- operating_cost_per_km;
- dimensiones activas.

## EXTERNAL

- services_available;
- availability source;
- PER_TRIP / PER_KM;
- ONE_WAY / ROUND_TRIP;
- cost values;
- compatibility.

No exigir campos de OWN a EXTERNAL ni viceversa.

# 5. EXACT SCHEMA

Para Ultimate MVP:

# 8. NORMALIZATION

Implementar normalizers versionados.

Cada dataset publicado debe conservar:

- raw hash;
- canonical hash;
- contract ID;
- contract hash;
- normalizer version;
- semantic entity;

Mismo input + mismo contrato + mismo normalizer:

→ mismo canonical representation/hash.

---

# 9. UNKNOWN VALUES

Mantener estrictamente:

```text
null != 0
unknown != unlimited
unknown availability != confirmed
```

Ejemplo:

`services_available = 0`

es válido y distinto de:

`services_available = null`.

Si se aplica default de disponibilidad externa:

debe quedar explícito como:

```text
ASSUMED
```

Nunca convertirlo silenciosamente en CONFIRMED.

# 12. CANDIDATE VS PUBLISHED

Separar claramente:

```text
candidate upload
```

de:

```text
published Pack Version
```

Un upload incompleto o inválido NO debe modificar:

- current Pack;
- approvals;
- graph readiness;
- Runs;
- history.

Sólo la publicación exitosa modifica el current pointer.

---

# 13. UPLOAD PIPELINE

Implementar el pipeline aprobado:

```text
Validate
↓
Journal
↓
Private Storage Upload
↓
Metadata
↓
Complete Manifest
↓

```

La publicación debe ser atómica desde el punto de vista del Case.

No permitir estado:

```text

but bytes missing
```

o:


# 14. RECOVERY

Implementar/reutilizar recovery para escenarios:

```text

```

No crear Pack Versions duplicadas por reintento.
