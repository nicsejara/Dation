# 5. FEASIBLE DISPATCH WINDOW

Para cada Trip construir determinísticamente su ventana.

Conceptualmente:

```text
earliest =

    planning_start,
    resource availability
)
```

```text

```

```text

    latest_due,
    other certified restrictions
)
```

# 6. HORIZON

El horizonte limita:

# DISPATCH DATE

Debe cumplirse:

```text
planning_start
<= dispatch_date
<= planning_end
```

Arrival puede ocurrir después de `planning_end`.

Ejemplo aprobado:

```text
dispatch: 8 Nov
arrival: 10 Nov
planning_end: 8 Nov
```

puede ser válido.

No cortar arrival al final del horizonte.

---

# 7. PRE-HORIZON

```text

```

No esconderlo como LATE.

No inventar una salida dentro del horizonte para aparentar cumplimiento.
