# Logistics Data Pack V3

Caso de ejemplo: un único site en Córdoba distribuye hacia ciudades de Córdoba y del resto del país.

- `orders.csv`: 30 órdenes. Las primeras siete columnas forman el núcleo mínimo para Asignación. Las columnas temporales y de prioridad completan Readiness para niveles posteriores.
- `fleet.csv`: 8 camiones reales (5 propios y 3 tercerizados), una fila por unidad. No existe el concepto de pool en el Data Pack.

Los dos archivos están completos para mostrar toda la cadena de Decision Readiness, aunque el usuario puede cargar sólo las columnas mínimas requeridas para Asignación.
